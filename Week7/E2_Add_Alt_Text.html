EDWARD · Week 7 A11y (E2) WCAG 1.1.1 Non-Text Content

E2: Writing Effective <img alt="..."> Attributes

Truong Phat Thuan (Edward) — Distinguishing informative, decorative, and functional images for screen readers.

1. Informative Image

Describe both the content and the data insight without saying "image of...".

Screen Reader: "Bar chart showing Gachon Computer Science enrollment rising 40 percent from 2024 to 2026, graphic"

2. Decorative Divider (alt="")

Use an empty string alt="" so screen readers skip visual flourishes completely instead of reading raw filenames.

Screen Reader: (Skipped completely — zero noise!)

3. Functional Icon Button

Describe the action (alt="Search"), not the icon's appearance (not "magnifying glass").

Screen Reader: "Search Run Directory Search, button"
